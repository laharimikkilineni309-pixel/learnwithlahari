A six-stage transition

01 · Programming

Weeks 1–4: one language, debugging, functions, OOP, small programs.

02 · DSA + Git

Weeks 5–8: common problem-solving patterns, version control, code review.

03 · Build apps

Weeks 9–14: frameworks, REST, databases, UI, auth, validation.

04 · Ship reliably

Weeks 15–20: Docker, CI/CD, deployment, logging, production fundamentals.

05 · Prove skills

Weeks 21–28: portfolio, README, project demos, interview preparation.

06 · Apply + improve

Months 8–12: target roles, interview feedback, deeper specialization.

The schedule is illustrative: adjust it to your experience, responsibilities, and available time.
