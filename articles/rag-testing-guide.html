How to test a RAG application

Validate retrieval and generation independently to pinpoint failures.

1. Test ingestion

Check parsing, chunk boundaries, metadata, access permissions, and freshness.

2. Measure retrieval

Use labeled questions to assess recall@k and precision@k, including difficult queries.

3. Validate answer grounding

Require citations to supporting passages and flag unsupported statements.

4. Exercise failure cases

Try empty results, contradictory documents, stale content, prompt injection, and unauthorized sources.

5. Observe end to end

Capture retrieved document IDs, latency, token usage, model version, and evaluation outcomes.

Key takeaway

Separate retrieval failure from generation failure before tuning either component.
