Testing AI agents and tool calls

A QA checklist for agents that plan, call tools, and act on behalf of users.

1. Validate tool contracts

Test schemas, argument validation, authentication, and least-privilege permissions.

2. Exercise orchestration

Check tool selection, multi-step state, retries, timeouts, and recovery after partial failure.

3. Guard consequential actions

Require confirmation for irreversible actions and test authorization boundaries.

4. Evaluate outcomes and traces

Review tool inputs and outputs, final state, user-visible answer, and cost.

5. Run adversarial scenarios

Inject misleading tool outputs and conflicting instructions to verify robust boundaries.

Key takeaway

A successful final message is not proof that an agent performed the right action.
